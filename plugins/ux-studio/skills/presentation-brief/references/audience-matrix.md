# Audience matrix

## Principles (sourced)

- Define audience and goals first. Executives want outcomes and a short method; give each audience one takeaway. Mixed "all stakeholders" messaging muddles the message.
  - Laura Ang, https://lauraang.substack.com/p/mastering-design-delivery-strategies
  - UX Design Institute, https://www.uxdesigninstitute.com/blog/presenting-ux-research-findings/
  - Donna Spencer, Presenting Design Work, https://books.alistapart.com/products/presenting-design-work
- Demo video structure: hook 0-5 s, problem 5-15 s, solution 15-30 s, proof 30-60 s, close/CTA. Lead with the outcome on the product, one use case per video, every claim backed by an on-screen visual, a short and a long cut from the same footage.
  - https://framia.converge.ai/page/en-US/blog/product-demo-video-script
  - https://www.flowjam.com/blog/startup-product-demo-video
  - https://screenhance.com/blog/how-to-make-a-product-demo-video
  - Lengths are conventions, not rules: about 60-90 s for executives, 2-5 min for walkthroughs.
- Repurposing: one core asset becomes many formats per persona. https://www.averi.ai/blog/ai-content-repurposing-techniques-for-b2b-marketing-turn-one-asset-into-20-touchpoints
  - In ux-studio (synthesis): the single source of truth is the showcase FLOWS definition (steps + copy + demo data). It drives the interactive tour, the video storyboard, slide screenshots and training clips.

## Audience x format matrix (synthesis, not a cited standard)

| Audience | Primary format | Length | Must include | Avoid |
|---|---|---|---|---|
| Executive sponsor / decision maker | 3-5 slides + showcase walkthrough (narrated video only if requested or accepted) | 60-90 s video; 10 min live | problem, before/after, impact, the decision asked | method detail, UI minutiae, jargon |
| Operational end users | guided interactive tour on realistic data (showcase) + training clips | 3-5 min self-paced; 30-120 s per clip | their daily task end to end, real vocabulary, error recovery | feature tours, abstract flows |
| Product owner / UX peers | showcase + critique session | 30-45 min | rationale, alternatives considered, open questions, edge states | polished sales narrative |
| Developers (handoff) | Design System artifact + showcase inventory + annotated flows | reference | tokens, states, edge cases, data shapes, motion specs | marketing video |
| Sales / marketing / customers | one-pager + showcase link (short branded video 16:9 + 9:16 only if requested or accepted) | 30-90 s | outcome hook, one use case, CTA, captions | unfinished screens shown as final |
| Field trainers | annotated step screenshots + quick reference sheet (step video clips only if requested or accepted) | 30-120 s per task | one task per clip, Spanish captions | long omnibus videos, music over voice |

## Using it

1. Start from the row; adjust length to the attention budget the user states.
2. Write the decision asked of that audience as a verb phrase ("approve the pilot for two sites").
3. If two audiences share a format, still keep two takeaways and two cuts.

## Measuring (synthesis)

- Name the decision per audience beforehand.
- Record the decision obtained and the open objections.
- After an executive video: a 3-question comprehension check.
- Feedback form with two prompts: "what would you change" and "what is unclear".
