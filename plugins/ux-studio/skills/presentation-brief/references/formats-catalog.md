# Formats catalog

| Format | Good for | Built by | Prerequisites |
|---|---|---|---|
| Showcase artifact (functional prototype in the format the brief chose: app only, app with guided tours, or the complete UX system) | Experience first: the app and replayable flows per persona; principles, design system, inventory and definitions/decisions only when chosen; methodology only in the complete UX system's appendix | `ux-designer` via `ux-studio:prototype-showcase` | BRIEF.md with its presentation format; design system decided; FLOWS with demo data |
| Design System artifact (claude.ai) | Developer handoff, brand consistency across all pieces | `ux-designer` via `ux-studio:design-system-builder` | Brand path chosen in BRIEF.md |
| Slides artifact (`/slides`) | Executive live sessions (3-5 slides), sales decks; exports PPTX/PDF | `ux-designer` | Takeaway and decision per audience; showcase screenshots |
| Design canvas (`/design`) | Exploring alternatives, critique sessions with product owner / UX peers | `ux-designer` | Open questions listed |
| Docs | One-pagers, quick reference sheets for trainers, written handoff notes | `ux-designer` | Final copy in the brief language |
| HyperFrames video (OPTIONAL: on request or accepted proposal; 16:9, 9:16, 1:1; mp4 or gif) | Executive 60-90 s, sales 30-90 s, walkthroughs 2-5 min | `video-producer` via `ux-studio:prototype-to-video` | Showcase FLOWS as storyboard source; captions plan; sonic stance |
| Training clips (OPTIONAL: on request or accepted proposal) | One task per clip, 30-120 s, Spanish captions, no music over voice | `video-producer` | One flow per clip; real vocabulary |

## Choosing

1. Start from the audience matrix; pick the primary format.
2. Add only formats that serve a named decision.
3. Short and long cuts of a video come from the same footage.
4. Every format reads from the same source of truth: showcase FLOWS.

## Notes

- Demo data stays labelled in every format.
- Slides and one-pagers use screenshots of the showcase, never separate mockups.
- Aspect ratios: 16:9 for meetings and web, 9:16 for mobile/social, 1:1 for feeds; gif for short loops in docs.
- Confirm tool availability (e.g. `/slides`, `/design`) in the user's account before promising a format.
