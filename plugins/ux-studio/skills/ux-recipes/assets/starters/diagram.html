Flujo de aprobación de un pedido

Desde que llega el pedido hasta que se avisa al cliente.

flowchart TD
  accTitle: Flujo de aprobación de un pedido
  accDescr: El pedido llega, se revisa el stock; si falta se pide reposición y luego se prepara el envío y se avisa al cliente.
  A([Llega el pedido]) --> B{¿Hay stock suficiente?}
  B -->|Sí| C[Preparar el envío]
  B -->|No| D[Pedir reposición al proveedor]
  D --> E[Recibir la reposición]
  E --> C
  C --> F([Avisar al cliente])
